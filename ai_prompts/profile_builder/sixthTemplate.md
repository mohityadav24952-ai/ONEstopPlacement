# NEW PORTFOLIO TEMPLATE REQUEST: "NEON 3D DEV"

I want to build a 6th portfolio template named "Neon 3D Dev". This template is highly inspired by modern, premium developer portfolios featuring dark themes, 3D elements, and subtle neon micro-animations. 

Please implement this template in Next.js/Tailwind CSS following these exact specifications:

## 1. GLOBAL STYLING & VIBE
- **Background:** Deep solid black (`#000000` or very dark grey `#09090b`).
- **Typography:** Modern, geometric sans-serif (like Inter or Poppins). Headings should be strictly UPPERCASE, bold, and oversized.
- **Accents:** Neon purple/pink and iridescent holographic gradients for buttons, hover states, and glowing borders.

## 2. NAVIGATION BAR
- Clean, transparent sticky header.
- **Left:** Minimalist initials logo (e.g., "SK").
- **Middle:** Text links (ABOUT, EDUCATION, SKILLS, PROJECTS, CP STATS, CONTACT) with a subtle underline on hover.
- **Right:** Small badge or pill saying "Available for opportunities" with a glowing green dot indicator.

## 3. HERO SECTION
- **Headline:** Huge, bold text (e.g., "HI, I'M [NAME]").
- **Centerpiece:** Space for a 3D avatar, Memoji, or floating 3D portrait.
- **Sub-headline:** Developer roles and CP stats separated by bullets (e.g., "SOFTWARE ENGINEER • CANDIDATE MASTER @CODEFORCES • 1500+ DSA").
- **CTA Buttons:** 
  - A "CONTACT ME" button with a rounded pill shape, dark background, and a bright neon pink/purple glowing gradient border.
  - A secondary "RESUME" button.
  - Minimalist social icons (GitHub, LinkedIn, Mail).

## 4. INFINITE TECH MARQUEE
- Directly below the hero, add a horizontal scrolling marquee.
- It should continuously scroll the user's tech stack (e.g., "Java * TypeScript * React.js * Next.js * MongoDB * AWS").

## 5. ABOUT ME & WHAT I DO
- **About:** A large text block where keywords (like "High-Performance", "Codeforces", "System Design") are highlighted in a brighter white or gradient, while the rest is slightly dimmed.
- **What I Do:** A 2x2 grid layout detailing core competencies (Full-Stack, DSA, System Design, UI/UX).

## 6. ACHIEVEMENTS & CP STATS (GRID)
- A 2x2 or 3x3 grid of dark cards.
- Each card should have a very subtle dark grey border that glows slightly on hover.
- Inside each card:
  - A centered icon at the top with a soft purple/pink glow behind it.
  - Bold metric (e.g., "1500+ Problems").
  - Subtext (e.g., "LeetCode & Codeforces Solved").

## 7. PROJECTS SHOWCASE
- A masonry or standard grid of project thumbnails. 
- Hovering over a project image should reveal the project title and tech stack with a dark overlay and smooth micro-animations (framing/scaling).

## 8. TECHNICAL SKILLS SECTION
- Categorized layout (LANGUAGES, FRONTEND, BACKEND, DATABASES, DEVOPS, CORE CS).
- Each category has its own row, with skills displayed as sleek, dark pill-shaped tags with grey text.

## 9. EDUCATION TIMELINE
- A vertical timeline or clean list layout displaying the degree/standard, institution name, duration, and CGPA/Percentage.

## 10. SPECIAL EFFECTS
- **Custom Cursor:** Integrate a custom 3D or oversized iridescent cursor pointer (if feasible, otherwise a custom glowing dot cursor).
- **Floating Assets:** Add random floating 3D shapes (like a moon, lego block, or abstract 3D geometry) in the background of the 'About' or 'Hero' sections.
